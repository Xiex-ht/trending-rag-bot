# 趋势破布机器人 · trending-rag-bot

**会自己更新知识的 QQ/企微 AI 助手** —— 基于 Dify + LangBot 的私有化 RAG 问答机器人，零公网成本部署。

QQ 群 @机器人即可问答，双人格自动路由（技术问答=专业模式 / 闲聊身份=小说角色模式）；知识库由自建管道每周自动更新，全程无人值守。

## 架构

```
QQ群/企微 ──WebSocket──▶ LangBot（消息网关）──▶ Dify API ──▶ qwen3.5-plus
                                                        ▲
定时管道（每周一 09:00）：                              │
Windows 任务计划程序 ─▶ 爬虫(GitHub周榜Top10+README摘要) ─▶ 知识库API对账同步
                        （新增上传 / 同名覆盖 / 过时清理）
```

## 核心特性

- **零公网部署**：全链路跑在一台 Windows 笔记本 + Docker Desktop 上，无需域名/备案/SSL/内网穿透
- **知识库自愈**：每周自动爬取 → 结构化入库 → 清理跌出榜单的过时文档
- **双重人格路由**：按问题类型自动切换技术顾问/小说角色两种人设，语气互不污染
- **可量化的 RAG 优化**：42 题评测集 + 三轮消融实验（见下表）

## RAG 优化实验结果

评测集：42 题（事实检索/内容归纳/汇总统计/比较推理/拒答对照），人工复核口径。

| 轮次 | 配置 | 准确率 | 说明 |
|---|---|---|---|
| 基线 | TopK3 · 纯向量检索 | 76% | 排名类问题大面积失败 |
| +1 | TopK5 · **混合检索** | 93% | 修复 7/10 排名错题 |
| +2 | + **面向检索的文档改写**（表格→自然语言排名句） | **97.6%** | 表格切块边界盲区清零，拒答题 2/2 零编造 |

关键发现：
1. 向量检索擅长语义相似、不擅长表格结构精确匹配——"为检索而写作"比调参更有效；
2. 关键词自动判卷在归纳/拒答题上系统性失真（机器 43% vs 人工 97.6%），评测方法论本身需要迭代。

## 快速开始

1. **部署 Dify**：官方 docker-compose 起全栈，配置模型供应商（需支持 thinking 关闭的模型避免思考泄漏）
2. **部署 LangBot**：`docker compose up -d`，WebUI :5300 创建流水线绑定 Dify 应用
3. **接入 QQ**：q.qq.com 创建机器人（沙箱模式免公网），LangBot 添加机器人实例
4. **建知识库**：运行 `crawler/` 管道生成文档，配置 `config_dify_kb.json`（参考 .example）后自动同步
5. **跑评测**：`set DIFY_APP_KEY=*** && python eval/eval_run.py --judge`

## 踩坑实录（均为真实排查）

- DNS 污染导致私有镜像仓库拉取失败 → 替代源拉取 + `docker tag` 恢复镜像名
- Windows cmd 中文路径/文件名编码连环坑 → ASCII 调度层 + Python 运行时定位
- Dify 知识库表格切块边界问题 → 面向检索的文档结构改写
- 任务计划程序密码验证失败 → "仅登录时运行 + 错过补跑"等效方案
